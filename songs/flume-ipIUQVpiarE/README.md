## Layout
| Folder | What | In git? |
|---|---|---|
| `audio/` | source downloads + float decodes | no (copyrighted, large) |
| `renders/` | band-split / excerpt listening aids, regenerated by scripts | no |
| `figures/` | spectrograms and pitch plots | yes |
| `data/` | measurements (json/csv) | yes |
| `scripts/` | repeatable analysis | yes |
